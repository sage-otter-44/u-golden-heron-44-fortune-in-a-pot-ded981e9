One kind, funny fortune for the houseplant on the windowsill — a concrete
scene (the pot, the sill, the cat) with a last-line twist, written as a
prediction, not a slogan or a care instruction.

> You will outgrow this pot by spring, shade the whole sill, and the cat will move over. It was your spot all along.

## Entry

`main.ts` writes the fortune above to `/output/entry.txt`: one line,
114 characters, no trailing newline. It guards the 120-character limit and
reads the file back to confirm it matches the fortune exactly.

Run it with:

```sh
node main.ts
```
